# Musiclet

**Musiclet** – Blooket-inspired platform by Ethan32.

## Nav / pages
- Stats
- Market
- Blooks
- Bazaar
- **Credits** (EthanM32 · Steven Montez)
- Settings

## Features
- Login / Register (localStorage – per browser/device)
- Pack opening + auto open
- Sell / list blooks, Bazaar
- Token trade, settings
- Owner / Co-owner panels
- Badges, custom PFP, animated background

## Repo
https://github.com/EthanM32122/Musiclet

## Deploy on Vercel
1. Import **EthanM32122/Musiclet** (branch **main**)
2. If the live site is outdated: Deployments → Redeploy → **uncheck** build cache

## Notes
Accounts are localStorage-only (not shared across devices until cloud auth is added).
