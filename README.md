# Musiclet

**Musiclet** – a Blooket-inspired music quiz platform.
Coded and owned by Ethan32.

## Live link
- Repo: https://github.com/EthanM32122/Musiclet

### Deploy free on Vercel
1. Go to [vercel.com](https://vercel.com) → sign in with GitHub
2. **Add New… → Project**
3. Import **EthanM32122/Musiclet**
4. Click **Deploy**
5. Your site will be live at a URL like `https://musiclet.vercel.app`

You can later add a custom domain (e.g. musiclet.org or cloaket.org) in Vercel → Settings → Domains.

## Features
- Landing page matching the original design
- Working Register + Login
- Accounts saved in browser localStorage
- Simple dashboard after login
